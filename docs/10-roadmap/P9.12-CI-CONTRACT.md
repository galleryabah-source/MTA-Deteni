# P9.12 — CI Contract

Status: contract implementation only.

## Source basis

The authoritative project work order places P9.12 after P9.11 Test Harness and before P9.13 Kernel Certification.

## Scope

P9.12 defines the CI quality-gate contract for the kernel.

A CI gate must:

1. install dependencies reproducibly;
2. run the deterministic test harness;
3. run type/static validation where configured;
4. reject a failing required gate;
5. expose machine-readable evidence suitable for certification.

The CI contract does not grant production deployment authority by itself.

## Required boundary

CI must preserve:

- no real detainee data in repository fixtures;
- no credentials/secrets in source or logs;
- no authorization bypass;
- no autonomous AI decision-making;
- migration freeze unless separately approved.

## Certification relationship

P9.12 produces evidence consumed by P9.13 Kernel Certification. A green workflow is evidence for the defined gates; it is not, by itself, certification.
