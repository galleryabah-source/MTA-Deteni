# P9.8 — Outbox Contract

Status: contract implementation only.

## Source basis

The authoritative project work order places P9.8 after P9.7 Transaction + Idempotency and before P9.9 Private Storage.

## Scope

P9.8 defines the durable-event boundary for reliable post-transaction dispatch.

An outbox event carries:

- event identity;
- aggregate identity;
- event type;
- payload fingerprint;
- occurrence time;
- dispatch status;
- attempt count.

The contract separates creation of a durable event record from its eventual external dispatch.

## Safety boundary

This checkpoint does not:

- create an outbox table;
- alter database schema;
- connect to production;
- publish to WhatsApp, email, queues, webhooks, or external systems;
- implement a dispatcher;
- invoke AI;
- mutate production records.
