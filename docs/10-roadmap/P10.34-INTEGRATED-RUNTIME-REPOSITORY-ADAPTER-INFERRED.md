# P10.34 — Integrated Runtime Repository Adapter

Status: CONTRACT / INFERRED

This is the composition boundary for the five core repositories already mapped to the observed production schema:

- detainee;
- placement;
- movement;
- leave;
- document.

Every repository operation receives the same governed runtime context:

- transactionId;
- requestId;
- correlationId;
- actorId;
- policyVersion.

This prevents domain repositories from becoming independent database escape hatches.

The adapter does not execute SQL and does not create database connections. Concrete execution must be supplied by the P9 runtime database adapter and remain subject to authorization, transaction/idempotency, audit, and outbox controls.

No migration, production mutation, external transport, storage upload, or AI operation is performed.

The checkpoint label is inferred.
