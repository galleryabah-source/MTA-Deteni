## Scope

P9.7 defines the application boundary for atomic transactions and idempotent command handling.

A transaction carries a transaction identifier and executes one logical operation through a transaction runner.

Idempotency uses:

- an idempotency key;
- a request hash;
- IN_PROGRESS / COMPLETED state;
- response hash after completion.

Replay is permitted only when the incoming request hash exactly matches the stored request hash. A different hash for the same key is a deterministic CONFLICT.
