# P9.9 — Private Storage Contract

Status: contract implementation only.

## Source basis

The authoritative project work order places P9.9 after P9.8 Outbox and before P9.10 Observability.

## Scope

P9.9 defines the application boundary for private object storage.

Each stored object has:

- object identity;
- bucket;
- object path;
- classification;
- content hash;
- content type;
- size.

Access is deny-by-default and requires:

1. authentication;
2. allowed scope;
3. classification permission.

## Safety boundary

This checkpoint does not:

- create or modify a storage bucket;
- upload real detainee documents;
- expose public objects;
- connect to production storage;
- alter database schema;
- invoke AI;
- mutate production data.

Migration Freeze remains TRUE and repository data remains synthetic-only.
