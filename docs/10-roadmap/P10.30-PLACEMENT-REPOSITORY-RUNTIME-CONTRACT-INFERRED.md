# P10.30 — Placement Repository Runtime Contract

Status: CONTRACT / INFERRED

Maps the placement domain to the read-only observed production table `public.mta_placements`.

Observed fields:
`id, detainee_id, block, room, since, until, metadata, created_at`.

The port is infrastructure-neutral and must be implemented through the runtime database adapter, transaction boundary, authorization kernel, and audit/outbox rules.

No schema change, SQL execution, production mutation, or AI operation is performed.
