# P9.13 — Kernel Certification Contract

Status: contract implementation.

## Source basis

The authoritative P9 sequence defines P9.13 as Kernel Certification after P9.12 CI.

P9.13 is the certification boundary for the kernel contracts P9.2 through P9.12. It consumes evidence; it does not replace the individual controls or CI execution.

## Certification inputs

Required contract areas:

- P9.2 Configuration & Environment Contract
- P9.3 Authentication Kernel
- P9.4 Authorization Kernel
- P9.5 Audit Kernel
- P9.6 Database Adapter & Database Contract
- P9.7 Transaction + Idempotency
- P9.8 Outbox
- P9.9 Private Storage
- P9.10 Observability
- P9.11 Test Harness
- P9.12 CI

## Certification rule

Certification is permitted only when every required input is explicitly evidenced as PASS/ACCEPTED by its authoritative gate.

A contract file existing in the repository is not equivalent to execution evidence.

Missing, failed, contradictory, or unverified evidence yields NOT_CERTIFIED.

## Safety boundary

Certification does not:

- create production data;
- mutate production schema;
- grant authorization;
- publish external messages;
- enable AI;
- bypass audit;
- authorize deployment without the applicable deployment controls.

Migration Freeze remains TRUE and AI_ENABLED remains FALSE.

## Evidence object

A certification record contains:

- certificationId
- kernelVersion
- evaluatedContracts
- evidenceRefs
- status: CERTIFIED | NOT_CERTIFIED
- issuedAt

The record is deterministic with respect to its supplied inputs.

## Current repository status

The repository currently contains contract implementations for P9.6-P9.12, but this document does not assert that their runtime tests or CI workflows have executed successfully.

Therefore this checkpoint defines the certification contract; it does not claim current kernel certification.
