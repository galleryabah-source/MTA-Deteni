# P9.13 — Kernel Certification Contract

Status: contract implementation.

## Source basis

P9.13 is the certification boundary for P9.2 through P9.12. It consumes evidence; it does not replace individual controls or CI execution.

## Certification rule

Certification is permitted only when every required input is explicitly evidenced as PASS or ACCEPTED by its authoritative gate. Missing, failed, contradictory, or unverified evidence yields NOT_CERTIFIED.

## Safety boundary

Certification does not create production data, mutate production schema, grant authorization, publish external messages, enable AI, bypass audit, or authorize deployment without applicable controls.

Migration Freeze remains TRUE and AI_ENABLED remains FALSE.

## Evidence object

A certification record contains certificationId, kernelVersion, evaluatedContracts, evidenceRefs, status, and issuedAt. The record is deterministic with respect to supplied inputs.

This checkpoint defines the certification contract; it does not claim current kernel certification.
