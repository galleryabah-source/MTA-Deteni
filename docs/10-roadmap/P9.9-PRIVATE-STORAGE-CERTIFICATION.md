# P9.9 Private Storage Certification

Status: IMPLEMENTED / DATABASE-VERIFIED / RUNTIME-BOUNDARY-VERIFIED

## Scope
P9.9 establishes private-object storage controls without introducing a public bucket or exposing object metadata to unauthenticated users.

## Production evidence
- Bucket: mta-deteni-private
- Bucket public flag: false
- File size limit: 10 MiB
- Allowed MIME types: image/jpeg, image/png, image/webp, application/pdf
- storage.objects RLS: enabled
- public.mta_storage_objects RLS: enabled
- Metadata uniqueness: UNIQUE(bucket_id, object_path)
- Metadata links to mta_documents with ON DELETE SET NULL
- Authorization role resolver: private.mta_current_role()
- Storage SELECT roles: OWNER, ADMIN, EDITOR, REVIEWER, AUDITOR
- Storage INSERT roles: OWNER, ADMIN, EDITOR
- Storage UPDATE roles: OWNER, ADMIN, EDITOR
- Storage DELETE roles: OWNER, ADMIN
- anon has no matching storage.objects policy; authenticated access is role-gated
- service_role retains privileged storage access
