# P9.17 — Repository Contract Boundary

P9.17 is an implementation checkpoint derived from the source's P9.6 database boundary and P9.7 transaction contract; it is not an authoritative source label.

Purpose: define the application-facing repository boundary without selecting a database driver or changing schema.

Repository mutations require:
- transactionId;
- requestId;
- correlationId;
- actorId;
- policyVersion.

Repositories expose read-by-id, insert, and update contracts. Concrete SQL, ORM implementation, schema migration, and production credentials remain outside this checkpoint.

This boundary is intended to be consumed by the integrated command/persistence pipeline.
