# P9.20 — Outbox Repository Boundary

P9.20 is an implementation checkpoint derived from the P9.8 outbox contract and P9.18 transaction/repository bridge; it is not an authoritative source label.

Purpose: define the repository boundary for transactional outbox persistence.

The boundary supports append, dispatched, and failed status transitions.

It does not implement a dispatcher or external transport. WhatsApp, email, queue, webhook, Cloudflare, or other external delivery remains outside this checkpoint.

Outbox persistence must participate in the same transaction boundary as the domain mutation when required by the command contract.
