# P10.5 — DOCUMENT & EVIDENCE HARDENING

Status: IMPLEMENTED / CONTRACT-VERIFIED / SCHEMA-PRESERVING

P10.5 strengthens the evidence boundary behind DOCUMENTED.

## Evidence chain

Temporary Exit
→ Document Artifact
→ Private Storage Object
→ SHA-256 Integrity
→ Revision
→ Approval
→ Audit
→ Outbox

## Invariants

- Document identity and actor identity are mandatory.
- Content integrity is represented by a valid SHA-256 hash.
- Evidence must bind to the private storage bucket/object path.
- Public document evidence is forbidden.
- Revisions start at 1 and increment sequentially.
- APPROVED/ISSUED artifacts require private storage evidence.
- ISSUED requires verified integrity and approval.
- Production schema is unchanged; no migration is introduced.

The domain contract does not claim live upload/download HTTP E2E or real-file cryptographic verification. Those require runtime evidence.
