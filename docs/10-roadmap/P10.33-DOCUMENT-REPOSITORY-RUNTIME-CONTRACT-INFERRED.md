# P10.33 — Document Repository Runtime Contract

Status: CONTRACT / INFERRED

Maps the document lifecycle persistence to the observed production table `public.mta_documents`.

The mapping explicitly preserves:
- document identity;
- revision/revision-of;
- template version;
- integrity hash;
- lifecycle timestamps;
- creator identity;
- payload.

This is aligned with the D5 requirement that historical documents remain bound to their template version and integrity evidence.

The repository must not bypass document lifecycle controls, authorization, audit, or storage boundaries.

No migration, production mutation, direct SQL execution, external transport, or AI operation is performed.

The checkpoint label is inferred.
