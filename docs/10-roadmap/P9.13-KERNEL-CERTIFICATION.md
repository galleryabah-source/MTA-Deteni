## System integration invariant

The P9 kernel is treated as one connected chain:

AUTHENTICATION
→ AUTHORIZATION
→ VALIDATION / SCOPE
→ DOMAIN MUTATION
→ TRANSACTION
→ AUDIT
→ OUTBOX
→ IDEMPOTENCY
→ OBSERVABILITY
→ TEST / CI

Private storage remains governed by the same authentication, role and classification model. AI remains an optional subsystem and cannot be a prerequisite for core detainee operations.

## Evidence rule

No external authenticated HTTP result is fabricated. KERNEL-CERT-010 remains PARTIAL until a real authenticated runtime health request is executed successfully.
