# P10.1 — Detainee Domain Contract

Status: contract implementation.

## Source basis

The project source explicitly orders P10 after P9.13 and names the first domain module **P10.1 DETAINEE**. The master roadmap defines the core administration domain as including master data detainee, status history, timeline foundation, provenance, completeness/verification, and restricted-domain boundaries. fileciteturn461file0

## Scope

This checkpoint establishes the Detainee domain boundary only:

- stable detainee identity;
- registration number;
- lifecycle status;
- data classification;
- verification state;
- create/update command shape;
- deterministic structural validation.

## Explicit non-scope

No:

- PostgreSQL repository;
- schema migration;
- production data;
- real detainee fixtures;
- API endpoint;
- authentication bypass;
- authorization grant;
- document generation;
- AI/OCR;
- WhatsApp intake.

Critical mutation must later pass authentication, authorization, validation, transaction/idempotency, audit, and applicable policy controls.

## Data boundary

Repository remains synthetic-data-only. Migration Freeze remains TRUE and AI_ENABLED remains FALSE.
