# P9.10 Observability Hardening

## Guarantees
- recursive redaction covers nested objects and arrays;
- sensitive key families include authorization, cookies, credentials, tokens, secrets and API keys;
- observability events require requestId, correlationId and timestamp;
- log levels are constrained to DEBUG/INFO/WARN/ERROR;
- observability continuity rejects request/correlation drift;
- metric samples require finite numeric values and execution correlation.

## Separation
Observability is operational telemetry, not immutable audit evidence. Audit remains the authoritative evidence chain.

## Governance
MIGRATION_FREEZE=TRUE. No schema mutation, migration, production secret exposure, or AI enablement.
