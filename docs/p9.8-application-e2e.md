## Runtime path
Application mutation -> PostgreSQL transaction boundary -> audit -> transactional outbox -> dispatcher claim -> payload validation -> application dispatch acceptance -> PUBLISHED.

Dispatcher: mta-outbox-dispatcher.

## Guarantees
1. Claims only PENDING events.
2. Uses database lease and SKIP LOCKED.
3. Validates deterministic payload identity.
4. Requires payload.eventId == outbox.event_id.
5. Requires payload.idempotencyKey == outbox.idempotency_key.
6. Completes only after application dispatch acceptance.
7. Releases failed events with bounded retry/backoff metadata.
8. Keeps service credentials server-side.
9. Does not call external queues/webhooks/email/WhatsApp in P9.8.
