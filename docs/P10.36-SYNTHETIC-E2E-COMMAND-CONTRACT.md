# P10.36 — Synthetic End-to-End Command Contract

**Status:** IMPLEMENTED / SYNTHETIC-ONLY

This gate composes the critical prerequisites for a future integrated domain journey without performing production mutation.

## Required sequence

`syntheticOnly → authorization → idempotency ACQUIRED → valid state → runtime ready → audit available → required outbox available`

Replay and request-hash conflict are never treated as a new executable mutation.

## Safety boundary

- no database mutation;
- no production authorization;
- no migration execution;
- no AI activation;
- no real detainee data;
- no external transport or durable publication.

## Evidence rule

The contract is a prerequisite gate. A production-readiness decision still requires observable controlled-nonprod execution evidence and separate PostgreSQL, offline/LAN, reporting/QR/device, Cloudflare, backup/restore and disaster-recovery gates.
