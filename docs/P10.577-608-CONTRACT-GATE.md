# P10.577–P10.608 — Pilot, Transport, UI Read-Model, Reporting Gate

## Purpose
Advance MTA DETENI as one integrated application without crossing the migration or production-access governance boundary.

## P10.577–P10.584 — Pilot readiness
- Evidence packet is explicit and machine-checkable.
- Certification is fail-closed: every control must be PASS/WAIVED.
- Production access remains prohibited.
- AI remains disabled.
- Migration freeze remains true.
- Evidence must identify checkpoint, control, status, reviewer and evidence reference where applicable.

## P10.585–P10.592 — API/application transport
- HTTP transport is an adapter boundary; domain services remain canonical.
- Mutations require correlation ID and idempotency key.
- Mutations require authorization and audit at the adapter/application boundary.
- Conflict/error semantics remain explicit; clients must not infer success from HTTP status alone.
- Read routes are separated from mutation routes.

## P10.593–P10.600 — Operator UI/read model
- UI consumes read models, not persistence tables directly.
- Role access is deny-by-default and remains aligned with OWNER/ADMIN/EDITOR/REVIEWER/AUDITOR.
- Mobile/tablet/desktop layouts must remain responsive; no domain logic is placed in presentation components.
- Operational QR remains verification-oriented: entry QR is valid during the Rudenim stay; individual QR is scanned for temporary exit and deportation workflows.

## P10.601–P10.608 — Reporting/export
- Regu jaga reporting is based on a versioned operational snapshot.
- Required report sections are validated before rendering/export.
- Provenance is retained for each report row.
- Document numbering and approval binding are represented without mutating the underlying schema.
- Exact visual reproduction of an existing official report remains a rendering/template implementation task; this checkpoint establishes the data contract only.

## Gate result
CONTRACT READY / SYNTHETIC TEST READY. No migration, live PostgreSQL connection, production credential, AI runtime, WhatsApp ingestion, OCR ingestion, or autonomous decision path is introduced by these checkpoints.
