# MTA DETENI — Temporary Exit & Assignment Letter Document Chain v1.0

## Purpose

Menghubungkan izin keluar sementara dengan penatausahaan Surat Tugas petugas Rudenim secara traceable tanpa mencampur kewenangan substantif dan administrasi surat.

## Document Chain

`Temporary Exit Request → Approval → Escort Requirement → Assignment Letter Administration → Letter Issued → Distribution → Execution → Return → Closure`

## Temporary Exit Categories

Master category harus configurable. Baseline:

1. Pemeriksaan kesehatan.
2. Rawat jalan/berobat di rumah sakit.
3. Rawat inap/rujukan rumah sakit.
4. Keperluan pemeriksaan atau koordinasi instansi terkait.
5. Keperluan hukum/administratif yang sah.
6. Keperluan pemulangan/deportasi.
7. Keperluan lain berdasarkan dasar dan persetujuan yang sah.

## Required Linkage

Setiap surat tugas harus dapat ditelusuri ke:

- deteni;
- izin keluar;
- dasar/approval;
- tujuan;
- jadwal;
- petugas;
- unit penerbit/penatausaha;
- nomor surat;
- template/version;
- timestamp;
- status;
- dokumen final.

## Authority Boundary

- KAMTIB mengelola kebutuhan operasional pengawalan sesuai kewenangan.
- Pejabat berwenang memberikan persetujuan substantif sesuai mandat.
- SUBBAG TU melaksanakan penatausahaan surat tugas.
- Petugas pengawal melaksanakan tugas.
- Sistem tidak boleh menyamakan pembuatan surat dengan persetujuan substantif.
