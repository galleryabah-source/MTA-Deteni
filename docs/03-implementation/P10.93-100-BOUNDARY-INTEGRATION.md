# P10.93–P10.100 Boundary Integration Contract

## Purpose

This checkpoint closes the gap between the existing runtime contracts and the next persistence boundary without opening PostgreSQL or provider access.

## P10.93–P10.94 — Authenticated command identity

The authenticated server principal is authoritative for actor and scope. Client-supplied identity is accepted only when it exactly matches the authenticated context; otherwise the command is rejected. The composed command carries request/correlation context, duty and classification metadata forward to the application boundary.

## P10.95–P10.96 — Controlled artifact download

A download grant is bound to artifact, actor and scope. The raw bearer token is returned only at issuance and the synthetic persistence model stores its SHA-256 digest. Grants are single-use, time-bounded and revocable. Actor/scope mismatch, invalid token, expiry, revocation and replay are fail-closed.

The production implementation must preserve these semantics using the existing persistent artifact-grant transaction contract; this checkpoint does not execute that migration.

## P10.97 — Provider isolation

External providers remain post-commit operations. A provider call without an observed successful transaction commit is rejected.

## P10.98–P10.99 — Evidence integrity

Release evidence binds the commit identity, safety state, test results and file digests. The manifest is content-addressed with SHA-256 and any mutation invalidates verification. Unsafe release state, failed tests or incomplete file digests cannot be promoted.

## P10.100 — Regression boundary

The deterministic P10 regression gate includes the P10.93–P10.100 suite. Certification still requires independently observable CI evidence. Synthetic execution is not equivalent to production database certification.

## Safety invariants

- Migration Freeze TRUE.
- AI OFF.
- Synthetic data only.
- No schema migration.
- No production database write.
- No provider/network activation.
- `main` is not an implementation lane.

## Next engineering boundary

P10.101+ must connect these contracts to the existing HTTP command gateway and unified temporary-exit service, reconcile them with the persistent artifact-grant transaction repository, and produce a controlled PostgreSQL adapter specification. Any database execution remains gated by governance and the migration-freeze policy.
