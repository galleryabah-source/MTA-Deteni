# P10.109–P10.116 — Controlled PostgreSQL Adapter Boundary

## Purpose

Define the production PostgreSQL adapter boundary without opening database execution while `MIGRATION_FREEZE=true`.

## Invariants

1. Authenticated server principal is authoritative for actor and scope.
2. Domain mutation, audit append and outbox intent are coupled to one transaction.
3. Any failure before commit causes rollback.
4. Idempotency uses the same operation/actor/scope/resource/payload fingerprint semantics already defined by the kernel.
5. Artifact grant consume is one atomic, scoped, unexpired `ACTIVE -> CONSUMED` transition and must affect exactly one row.
6. Artifact grant revoke is one atomic, scoped `ACTIVE -> REVOKED` transition and must affect exactly one row.
7. Provider/network calls never execute inside the persistence transaction.
8. Schema-changing execution is blocked while migration freeze is active.
9. AI remains disabled on the controlled certification path.
10. Audit hash-chain material is generated and persisted as part of the same critical transaction.

## Explicit non-actions

- No migration was executed.
- No production connection was opened by this contract.
- No real detainee data is used.
- No provider was activated.

## Gate

P10.109–P10.116 are implementation-boundary checkpoints, not production certification. Independent CI evidence remains required before any PASS or release claim.
