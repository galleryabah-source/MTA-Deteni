# P12.1281–1360 — Release Gate and Controlled Operator Surface

The release decision is explicitly derived from safety, reconciliation, workflow approval and execution certification evidence.

`READY` requires all of:
- synthetic-only data;
- migration freeze;
- AI disabled;
- production authorization absent;
- reconciliation matched;
- workflow approved;
- execution certified.

Otherwise the result is `BLOCKED`.

The operator surface contract requires action, aggregate, detainee and correlation identity and rejects actor/correlation drift before the application layer is invoked.

This is a governance boundary, not a production deployment authorization. Current project execution remains uncertified while observable CI/local telemetry is unavailable.
