# P10.905–936 — Synthetic Release-Candidate Matrix & Pre-Authorisation Audit

## Purpose

Close the P10.904 release-readiness contract without crossing the governance boundary. This gate makes the release-candidate evidence model explicit and provides a final application-boundary audit contract.

## Checkpoint groups

| Checkpoints | Focus | Target |
|---|---|---|
| P10.905–912 | UI/read-model boundary, responsive surface, server-authority assertions | SYNTHETIC |
| P10.913–920 | QR context/state outcomes and reporting snapshot invariants | SYNTHETIC |
| P10.921–928 | operator workflow authority, conflict/review behavior, role boundaries | SYNTHETIC |
| P10.929–936 | evidence completeness, safety invariants, pre-authorisation boundary audit | SYNTHETIC |

## Release-candidate rule

A matrix is **READY** only when it is non-empty, every check is PASS, every check has an evidence reference, and target identity is consistent. A NON_PRODUCTION matrix may contain only NON_PRODUCTION evidence. No matrix result authorises production access.

## Final boundary audit

The pre-authorisation audit must preserve all of these invariants:

- Migration Freeze = TRUE;
- AI = OFF;
- Production access = NOT AUTHORIZED;
- direct operational mutation from UI/read-only surfaces = FALSE;
- repository test data = synthetic only;
- no real detainee PII, credentials, health records or operational exports in repository;
- no schema migration;
- no live PostgreSQL execution without an explicitly approved non-production target;
- QR remains an operational verification boundary, not a free-form mutation channel;
- report output remains an immutable/versioned snapshot boundary;
- leadership remains read-only for operational records;
- PERKES health data remains outside non-health operational surfaces.

## Evidence discipline

The repository may define and test contracts, but must not claim CI PASS, database PASS, production readiness, or operational authorisation without observable evidence. `NOT_RUN` is not equivalent to PASS.

## Exit condition

P10.936 is complete when the synthetic release matrix and boundary audit contracts are implemented and covered by deterministic tests. The project then remains **pre-authorisation** until a later governance gate explicitly permits controlled non-production integration.
