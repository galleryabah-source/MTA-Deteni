## IDOR protection

Resource identity supplied by the client is untrusted. Authorization must be evaluated against the resolved resource and the actor's effective scope before sensitive details are returned.

## Error contract

External responses remain generic enough to avoid leaking account/resource existence. Internal reason codes are auditable and testable.

## Release gate

P10.26 is satisfied only when every protected endpoint class has an identified enforcement point and a negative test. This document does not authorize production activation.
