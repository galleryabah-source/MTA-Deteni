- Classification: **SCAFFOLD_READY**

## Components

```text
Escort command
 → authorization/scope
 → assignment validation
 → personnel/conflict checks
 → transaction kernel
 → audit/outbox
```

Required operations: createAssignment, validateAssignment, substituteEscort, cancelAssignment, getAssignment, getAssignmentHistory, bindEscortDocument.

Assignments must reference a valid approved/documented temporary exit. Substitution and cancellation are explicit events. Document generation is downstream of accepted assignment state. TU administrative authority and KAMTIB operational authority remain distinct.

## Test gate

Synthetic tests cover valid assignment, unavailable/conflicting personnel, wrong scope, substitution, cancellation, missing approval, missing exit document, duplicate replay, and audit rollback.

## Safety

No migration or live database mutation is authorized by this scaffold.
