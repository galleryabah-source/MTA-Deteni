# P9.6 — Local PostgreSQL Introspection Harness

Status: IMPLEMENTED — NOT CERTIFIED

## Safety boundary
Strictly read-only. Requires DATABASE_URL, refuses Supabase URLs and write mode, queries PostgreSQL catalog/information_schema metadata only, writes evidence under artifacts/p9.6/, and does not execute migrations.

## Execution
export DATABASE_URL='postgresql://USER:PASSWORD@localhost:5432/mta_deteni_p96'
bash scripts/p9.6-run-introspection.sh

Output: artifacts/p9.6/local-postgres-introspection.json

## Evidence captured
- PostgreSQL server/database/user identity
- schemas
- tables/views/materialized views/foreign tables
- columns
- constraints
- indexes
- functions and security-definer state
- triggers
- RLS configuration
- RLS policies
- extensions

## Reconciliation rule
This is the actual side of the P9.6 matrix. It must be compared against repository expected-schema evidence before any migration decision.

A local MISSING, EXTRA, or CONFLICT result is not by itself a production migration requirement.

## Prohibitions
- No production Supabase connection.
- No apply_migration.
- No DDL/DML.
- No schema mutation.
- No AI canonical write capability.
