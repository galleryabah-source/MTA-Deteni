# P12.121–P12.240 — Integrity Composition Gate

## Purpose

Strengthen the MTA DETENI application boundary without changing the database schema or enabling production execution.

## P12.121–160 — Shared transaction context

Every mutation context carries one transaction identity bound to:

- transaction ID;
- actor ID;
- correlation ID;
- aggregate ID.

Audit and outbox persistence must use the same identity. Production adapters must execute domain mutation, audit, outbox and idempotency completion under the same database transaction context.

## P12.161–200 — Persistent idempotency contract

Idempotency records bind:

`key + fingerprint + actor + correlation + aggregate`

States are `IN_PROGRESS` and `COMPLETED`.

A replay is accepted only when the complete identity matches and the prior operation is completed with a stored result. A different fingerprint or identity is a conflict.

## P12.201–240 — Authorization policy matrix

Operational permissions are explicitly assigned by domain:

- RAP: detainee registration, administration, reporting;
- PERKES: health records and health workflows;
- KAMTIB: placement, movement, headcount, temporary-exit validation, escort assignment, operational QR;
- SUBBAG TU: escort-document administration;
- LEADERSHIP: oversight read and directive authority.

Leadership is explicitly prevented from direct operational editing through this policy contract.

## Read-model rule

Read-model projection remains downstream of a committed mutation. It is not part of the mutation transaction. Projection must therefore be rebuildable and fed from committed operational evidence/outbox records.

## Safety

Migration Freeze = TRUE.

AI = OFF.

Repository data = SYNTHETIC ONLY.

Production access = NOT AUTHORIZED.

Live PostgreSQL execution = BLOCKED pending explicit governance clearance and an approved non-production target.

No schema migration is introduced by this gate.

## Verification

Static regression coverage is provided for transaction identity, replay safety and domain authorization. This is contract evidence only until observable CI or authorized local execution telemetry exists.
