# P10.157–P10.164 — Pre-Certification Consistency Gate

## Status

IMPLEMENTED as a synthetic/readiness control. It does not authorize live PostgreSQL execution, migration, provider activation, AI activation, or certification.

## Purpose

Prevent inconsistent evidence packages from reaching a certification decision. Regression evidence, integrity evidence, and the release manifest must describe the same checkpoint, commit, safety state, and test population.

## Controls

- **P10.157:** Require a complete regression/integrity/release evidence package.
- **P10.158:** Require one expected checkpoint across all evidence artifacts.
- **P10.159:** Require one expected commit SHA across all evidence artifacts.
- **P10.160:** Reject any regression evidence that is not PASS.
- **P10.161:** Require test-count agreement and zero missing tests.
- **P10.162:** Revalidate synthetic-only, test-environment, AI-OFF and Migration-Freeze safety on evidence inputs.
- **P10.163:** Revalidate release-manifest schema and release safety independently.
- **P10.164:** Convert any consistency failure to BLOCKED; never manufacture PASS from incomplete or contradictory evidence.

## Boundary

This gate is intentionally downstream of the regression and evidence-integrity gates. A synthetic PASS means the evidence package is internally consistent only. It is not proof that PostgreSQL, RLS, production infrastructure, deployment, or operational procedures are certified.

## Required release sequence

1. Execute authoritative synthetic regression gate.
2. Validate evidence integrity and output digest.
3. Build/validate release evidence manifest.
4. Run this pre-certification consistency gate.
5. If any stage is BLOCKED or FAIL, stop the release path.
6. Only after independent governance clearance may a separate controlled non-production PostgreSQL verification package be executed.

## Safety invariants

- `MIGRATION_FREEZE=TRUE`.
- `AI_ENABLED=false`.
- Synthetic fixtures/test doubles only.
- No live PostgreSQL writes.
- No schema migration.
- No provider/network operation in the critical transaction path.
- No production detainee data or secrets.
