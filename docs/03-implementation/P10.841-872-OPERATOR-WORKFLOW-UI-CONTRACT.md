# P10.841–P10.872 — Operator Workflow UI Contract

## Canonical workflow
RAP request → KAMTIB validation → Leadership approval → SUBBAG TU document → KAMTIB escort assignment → departure → return → Leadership oversight.

## UI rules
- Each state displays its current owner and next permitted transition.
- A user never sees a mutation control as evidence of authorization; the server remains authoritative.
- Invalid or stale transitions surface a safe conflict/review state.
- Leadership oversight is read-only.
- PERKES health information is excluded from generic detainee/operator surfaces.

## Mobile/tablet behavior
- Primary action remains reachable without horizontal scrolling.
- Critical status and safety alerts remain visible above secondary detail.
- Tables may collapse into cards without changing the underlying read-model contract.

CONTRACT READY / RESPONSIVE WORKFLOW READY.
