# MTA DETENI — P13.5041–5240 Evidence Convergence

## Purpose

Advance the project from an execution-contract-only state toward evidence-driven pre-production convergence without claiming observations that have not actually been executed.

## Checkpoints

### P13.5041–5080 — Execution Observation Ledger

Records actual controlled non-production observations with plan identity, stage, control, evidence, timestamps, exit code, output identity and status. A PASS cannot carry a non-zero exit code, timestamps must be valid and ordered, and observations from another plan are rejected.

### P13.5081–5120 — Execution Environment Boundary

Locks the execution target to CONTROLLED_NONPROD, synthetic-only data, AI OFF, migration freeze, no production authorization, no live database approval, and local/isolated LAN networking with external integrations disabled.

### P13.5121–5160 — Browser/LAN Acceptance Matrix

Defines required observable acceptance across the PC server, tablet and smartphone surfaces, including online, offline read-only, reconnect, pairing and revocation scenarios. Missing surface/scenario coverage is a gate failure.

### P13.5161–5200 — Report Source/Template Fidelity

Requires deterministic artifact generation, source snapshot identity, exact source-field/template-element equality and observable visual review. This is a verification boundary; it does not invent the supplied report's layout or field values.

### P13.5201–5240 — Evidence-Driven Pre-Production Gate

Derives BLOCKED, OBSERVATION_PENDING or READY_FOR_HUMAN_APPROVAL. The latter is reachable only when the execution plan, observation ledger, browser/LAN matrix, report fidelity, recovery rehearsal and security review are all evidenced as passed. It is not production authorization.

## Governance

- Migration Freeze remains TRUE.
- AI remains OFF.
- Repository remains SYNTHETIC ONLY.
- Production remains unauthorized.
- No schema migration is introduced.
- No live PostgreSQL execution is introduced.
- No evidence is fabricated from source presence.

## Required real execution before certification

1. Run typecheck and regression suites in controlled non-production.
2. Start the local runtime and capture health evidence.
3. Execute browser smoke and role navigation.
4. Verify PC server with trusted tablet/smartphone LAN clients and offline/reconnect behavior.
5. Render the approved daily guard report from the supplied source template and perform visual review.
6. Rehearse backup/restore, integrity, journal replay and read-model rebuild.
7. Perform security/regression review.
8. Aggregate only observed evidence into the final index.

Until those observations exist, the project status must remain observation-pending.
