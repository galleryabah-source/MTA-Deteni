## Components

```text
Placement API
 → Authorization/scope
 → Placement service
 → capacity + active-placement predicates
 → transaction kernel
 → audit/outbox
```

Required operations: assignPlacement, transferPlacement, closePlacement, getCurrentPlacement, getPlacementHistory, getCapacityView.

Placement writes must be atomic, version-aware, idempotent, and reject conflicting active occupants. Historical placement remains immutable. Capacity is enforced server-side. UI cannot bypass these predicates.
