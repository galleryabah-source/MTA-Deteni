## Purpose

Define assignment and execution of escort operations as a controlled continuation of an approved temporary exit.

## Rules

1. Escort assignment references an approved and documented temporary exit.
2. Assignment identifies required personnel, responsibility, schedule/window, and operational context.
3. Personnel assignment is subject to authority, availability, conflict, and scope validation.
4. Substitution or cancellation is an explicit audited event, not a silent overwrite.
5. Surat Tugas Pengawalan is generated only from the accepted assignment state and does not itself authorize the underlying exit.
6. Departure requires the approved exit and valid escort state where escort is mandatory.
7. Return closes the operational execution while retaining assignment history.
8. TU administers/registers/generates the assignment-letter document within its authority; substantive exit approval remains outside TU's document-administration role.
9. KAMTIB controls operational escort execution within its authority.
10. All material transitions use authorization, idempotency, audit, and transaction coupling.

## Acceptance

Synthetic tests cover assignment, conflict, unauthorized assignment, substitution, cancellation, document dependency, departure prerequisite, return, duplicate replay, and audit integrity failure.

## Dependency

`Temporary Exit → Escort → Document Engine → Approval/Leadership`.
