## Purpose

## Evidence discipline

A harness result is structurally valid only when its identity, observation count, packet identity, command identity and output digest are coherent. Certification still requires observable execution telemetry. `NOT_RUN`, missing output identity, non-zero exit codes, target mismatch, or fabricated evidence remain blocked.

## Application boundary

The harness is an evidence adapter, not an operational workflow. It cannot create, approve, move, release, deport, or otherwise mutate detainee records. It does not bypass RAP, PERKES, KAMTIB, SUBBAG TU or HEAD RUDENIM authority boundaries.
