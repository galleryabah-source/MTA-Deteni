# P10.33 — Security Boundary Finalization

Status: PREPARED — synthetic/security contract.

1. Authentication and authorization remain separate.
2. Client claims are untrusted; effective authority is server-resolved.
3. Deny-by-default covers identity, permission, scope, duty, classification, resource, state, policy and SoD.
4. Super Admin cannot bypass operational authority.
5. Sensitive lookup cannot disclose resource existence through authorization ordering.
6. Critical mutation is transactional, audited and idempotent.
7. External provider work is post-commit only.
8. Artifact download requires a bound, expiring, atomic single-use grant.
9. Audit evidence is immutable/append-only and hash-verifiable.
10. AI is assistive and OFF by default and cannot become a critical dependency.
11. Migration remains frozen until explicit governance approval and controlled DB verification.
12. Evidence must be independently observable before certification.

This consolidates security contracts; it is not production certification.
