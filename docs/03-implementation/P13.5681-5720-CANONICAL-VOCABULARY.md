# MTA DETENI — P13.5681–5720 Canonical Vocabulary Gate

## Decision

The governance term `HEAD_RUDENIM` is canonical for the substantive leadership/oversight actor. `LEADERSHIP` must not remain an independent authorization/domain identity.

## Compatibility rule

If historical contracts or code still expose `LEADERSHIP`, it is treated only as a compatibility alias and must resolve to `HEAD_RUDENIM`. New permissions, audit events, API contracts, UI labels and policy rules must use `HEAD_RUDENIM`.

## Authority boundary

`HEAD_RUDENIM` has oversight/read-only operational visibility and authority for petunjuk, arahan, rekomendasi and disposisi. It is denied direct operational mutation unless a separately approved governance rule explicitly changes that boundary.

## Acceptance invariants

- No new canonical permission uses `LEADERSHIP`.
- No authorization decision may distinguish `LEADERSHIP` from `HEAD_RUDENIM` as separate substantive roles.
- Audit records use the canonical actor/domain vocabulary.
- UI and reporting use the canonical label.
- Compatibility mapping, if retained, is one-way and explicit.

## Migration policy

This is a vocabulary normalization only. It does not authorize a database migration. Existing data-model and migration freezes remain unchanged.
