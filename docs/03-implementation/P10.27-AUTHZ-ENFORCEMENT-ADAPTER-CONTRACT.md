# P10.27 — Authorization Enforcement Adapter Contract

Status: PREPARED — no production activation.

Every protected runtime command obtains authenticated context and invokes the existing authorization kernel before domain mutation or sensitive disclosure.

`HTTP → AuthenticatedContext → authorize() → DENY / validate → domain command`

Security context is server-resolved: user/session status, effective permissions, scope, operational assignment/duty, classification clearance and policy version. Client-provided role/scope/duty/classification claims are never authoritative.

Super Admin cannot satisfy operational duty requirements. Critical mutation remains authorization → validation → domain → audit → outbox inside the transaction boundary. Providers run only after commit.

No production identity provider, session store, database policy, migration, provider or real data is activated.
