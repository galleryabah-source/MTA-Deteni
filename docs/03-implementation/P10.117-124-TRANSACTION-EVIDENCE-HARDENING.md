# P10.117–P10.124 — Transaction & Evidence Hardening

## Scope

This checkpoint hardens the persistent artifact-grant transaction boundary and makes the release evidence manifest capable of carrying an explicit audit-chain anchor. It remains contract/synthetic-only.

## P10.117–P10.119

Consume and revoke transitions now have explicit transaction wrappers. The repository requires exactly one affected row; audit and outbox callbacks receive the same transaction client. Callback failure therefore rolls back the critical transaction. Provider/network work remains outside this boundary.

## P10.120–P10.122

Release evidence may carry `auditEvidence = { eventCount, headHash }`. The anchor is included in the canonical manifest hash, so post-manifest mutation is detected. The audit kernel exposes canonical material and `auditChainEvidence()` to derive a verified chain count/head without duplicating hash logic.

## P10.123–P10.124 Controlled verification matrix

| Scenario | Expected result | Environment |
|---|---|---|
| Normal consume | One ACTIVE grant → CONSUMED; audit/outbox coupled | Synthetic / later controlled DB |
| Concurrent consume | Exactly one transition succeeds; loser fails closed | Controlled DB only |
| Expiry race | Expired grant cannot consume | Controlled DB only |
| Wrong actor/scope/object | Zero rows; transition rejected | Synthetic + controlled DB |
| Revoke race | Exactly one ACTIVE → REVOKED transition | Controlled DB only |
| Audit failure | Entire transaction rolls back | Synthetic + controlled DB |
| Provider isolation | No provider before COMMIT | Synthetic + controlled DB |
| Migration freeze | Schema-changing execution blocked | Controlled certification |
| AI | AI disabled on certification path | Controlled certification |

## Safety boundary

Migration freeze remains TRUE. No migration, schema-changing SQL, production write, real detainee data, provider call, or AI execution is introduced by these checkpoints. These are implementation/verification boundaries, not production certification.
