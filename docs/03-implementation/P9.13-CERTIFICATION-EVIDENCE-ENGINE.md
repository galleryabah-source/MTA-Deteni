# MTA DETENI — P9.13 Certification Evidence Engine

**Status:** IMPLEMENTED / CERTIFICATION NOT GRANTED

## Purpose

P9.13 now has a deterministic evidence model so certification cannot be inferred from missing CI output or partial execution.

## Rules

- Allowed states are exactly `PASS`, `FAIL`, `BLOCKED`, and `NOT_RUN`.
- Empty evidence is invalid.
- Unknown result states are rejected.
- Evidence uses canonical JSON and SHA-256 for deterministic integrity verification.
- Any `FAIL` blocks certification.
- Any `BLOCKED` blocks certification.
- Any `NOT_RUN` blocks certification.
- Certification is granted only when every required check is explicitly `PASS`.

## Current gate boundary

The engine itself is executable and deterministic, but MTA DETENI remains **NOT CERTIFIED** because the external CI execution evidence and runtime/domain integration gates are not yet established.

## Safety boundary

No schema migration, production database connection, real detainee data, or production secret is required by this checkpoint. AI remains OFF.
