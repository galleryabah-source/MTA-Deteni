# P10.221–P10.228 — PostgreSQL Verification Evidence Contract

## Purpose

Define the evidence produced by a future controlled non-production PostgreSQL verification. Evidence is designed to prove behavior, not merely application responses.

## P10.221 — Run manifest

Bind run ID, commit SHA, contract versions, environment flags, target reference, fixture namespace, and start/end timestamps.

## P10.222 — Transaction evidence

For every scenario record the observable outcome:

```text
BEGIN → precondition → mutation → audit/outbox → COMMIT
```

or:

```text
BEGIN → failure → ROLLBACK
```

A successful HTTP response without transaction evidence is insufficient.

## P10.223 — Authorization evidence

Record the authorization decision class, policy version, actor/scope test identity, and affected-row result without exposing sensitive payloads.

## P10.224 — Concurrency evidence

For race scenarios, bind all competing attempts to one scenario ID and record exactly one winner where the contract requires single consumption. Losing attempts must fail closed.

## P10.225 — Expiry/revoke evidence

Verify database-time predicates for expiry and mutually exclusive terminal transitions. Application timing alone is not sufficient.

## P10.226 — Audit/outbox evidence

Record event count, event identity, hash-chain head, outbox identity/state, and transaction coupling. A mutation without its mandatory evidence is a failed scenario.

## P10.227 — Isolation evidence

Prove that provider/network work is not performed before commit. AI remains OFF for certification-path execution.

## P10.228 — Evidence classification

The complete run is classified:

```text
PASS
FAIL
BLOCKED
ABORTED
```

Any hard safety-gate violation prevents a PASS classification.

## Evidence integrity

The evidence manifest must be cryptographically bound and independently verifiable. Mutation of an evidence artifact after capture must invalidate the manifest.

## Safety invariant

> Evidence must prove the transaction and security behavior, not merely the final API response.
