# P11.033–P11.064 — QR / Report Contract Composition

## Scope

This gate strengthens the application boundary by exercising the deterministic QR outcome/action mapping and the report snapshot → artifact contract using synthetic fixtures.

## Controls

- P11.033–040: QR context/outcome → next-action determinism;
- P11.041–048: report snapshot identity and mandatory section preservation;
- P11.049–056: fail-closed rejection of incomplete report identity/approval binding;
- P11.057–064: explicit synthetic-only gate identity.

## QR Semantics

The three operational contexts remain distinct: `RUDENIM_STAY`, `TEMPORARY_EXIT`, and `DEPORTATION`. Accepted results continue; context mismatch requires review; other rejected/expired/future/inactive outcomes stop the workflow.

## Report Semantics

The report artifact remains derived from an immutable-style snapshot contract carrying snapshot identity, source version, document number, approval binding, provenance and the mandatory Regu Jaga sections.

## Safety

No QR scan is connected to live operational records. No report is generated from real detainee data. No database or external service is contacted.
