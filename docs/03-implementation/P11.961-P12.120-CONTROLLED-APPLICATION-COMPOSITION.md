# MTA DETENI — P11.961–P12.120 Controlled Application Composition

## Scope

This checkpoint advances the contract-ready integrity chain into a controlled application-service boundary without touching the database schema, migrations, production credentials, or live production data.

## Implemented checkpoints

### P11.961–P11.1024 — Transactional mutation orchestration

The application boundary now requires:

`Authorization → Transaction → Idempotency decision → Domain mutation → Audit → Outbox → Idempotency completion`

Replay returns the stored result without a second domain mutation. A fingerprint mismatch is a conflict. The transaction adapter is responsible for making the mutation, audit, outbox, and idempotency completion one atomic persistence unit.

### P11.1025–P11.1088 — Operator command/read surface

Operator commands have a stable command ID, actor context, permission, fingerprint and payload. Commands are routed through the transactional mutation boundary, while dashboard reads remain behind a dedicated read port.

### P11.1089–P11.1160 — Temporary-exit application adapter

Temporary-exit creation and state advancement are bound to the existing `MtaWorkflowService`. Audit and outbox envelopes are generated only after the canonical workflow returns its domain result. Deportation remains a separate workflow/context; `COMPLETED` is not reinterpreted as deportation.

### P11.1161–P12.120 — Command/read-model composition

The operator application facade now composes mutation execution with read-model projection. This closes the intended application flow:

`UI/API Command → Authorization → Idempotency → Transaction → Domain Workflow → Audit/Outbox → Read Model → Operator UI/Report`

## Contract requirements

1. Every mutation requires actor identity, correlation ID and idempotency key.
2. Authorization is deny-by-default at the application boundary.
3. Idempotency fingerprint conflicts must not mutate the domain.
4. Audit actor/correlation identity must match the command actor.
5. Audit and outbox aggregate identity must match.
6. Production persistence adapters must use a transaction context shared by domain mutation, audit, outbox and idempotency completion.
7. Read-model projection occurs only after the mutation envelope is returned from the transactional boundary.
8. Repository remains synthetic-only.
9. Migration Freeze remains TRUE.
10. AI remains OFF.
