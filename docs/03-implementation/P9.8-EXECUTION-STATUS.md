# MTA DETENI — P9.8 Executable Implementation Status

**Status:** IMPLEMENTED / EXECUTION EVIDENCE PENDING

## Scope

The branch contains a dependency-free executable outbox/idempotency foundation aligned to the P9.8 contract. It remains an in-memory kernel test double until the approved PostgreSQL schema and adapter integration are available.

## Implemented invariants

- immutable event identity via `eventId`;
- event contract validation;
- correlation metadata requirement;
- `PENDING → PROCESSING → SUCCEEDED` lifecycle;
- retry lifecycle;
- dead-letter lifecycle;
- lease owner and lease expiry;
- stale-lease recovery;
- duplicate event identity rejection;
- deterministic request fingerprinting;
- same-key replay;
- same-key/different-payload conflict;
- worker lease ownership on completion/retry/dead-letter;
- AI/provider independence at kernel level.

## Deliberate boundary

This implementation does **not** claim transactional database atomicity. That requires integration with the approved database adapter and schema. No migration is performed here.

## Evidence

The executable Node test suite is included under `test/p9-transaction-outbox.test.mjs`.

GitHub Actions is configured to execute the suite, but the connector currently exposes workflow failure status without actionable runner step logs. Therefore CI is not represented as PASS until independently observable evidence is available.

## Gate
