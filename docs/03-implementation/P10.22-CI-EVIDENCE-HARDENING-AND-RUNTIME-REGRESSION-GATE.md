# P10.22 — CI Evidence Hardening & Runtime Regression Gate

## Status

IMPLEMENTED — certification remains fail-closed pending independently observable GitHub Actions evidence.

## Objective

Create one deterministic CI entry point for the synthetic MTA DETENI runtime suite. The gate distinguishes application test failure from safety blocking and preserves evidence when the test command fails.

## Safety contract

The workflow is permitted to execute only when:

- `APP_ENV=test`;
- `AI_ENABLED=false`;
- `MIGRATION_FREEZE=true`;
- `.env` and `.env.local` are absent;
- only repository test fixtures and test doubles are used.

## Regression scope

The authoritative manifest is `scripts/p10-runtime-regression-gate.mjs`. It enumerates the P9 kernel tests and the complete P10 synthetic regression set through P10.132. The workflow does not maintain a second manually duplicated test list.

## Classification

- `PASS`: all required files exist, the safety contract is satisfied, and the complete suite exits successfully;
- `FAIL`: the safety contract is satisfied and the complete suite exits unsuccessfully;
- `BLOCKED`: a safety condition or required-file precondition is not satisfied.

A classification is not production certification.

## Evidence

The gate emits:

- `artifacts/p10-runtime/classification.json`;
- `artifacts/p10-runtime/test-output.txt`.

Evidence contains only operational metadata, synthetic classification, test process status, commit/run identity supplied by GitHub, and a SHA-256 digest of test output. No detainee data, document contents, credentials, tokens or secrets are intentionally emitted.

## Integrity coupling

`P10 evidence integrity` independently validates the generated evidence against the current P10.140 checkpoint, safety flags, synthetic-only boundary, required-test count structure, missing-test state, classification, commit identity and output digest. Integrity PASS does not convert a regression `FAIL` or `BLOCKED` classification into PASS.

## Workflow behavior

Diagnostics and evidence are retained with `if: always()` so a failing regression suite cannot silently discard evidence. `workflow_dispatch` remains available for controlled manual reproduction without changing the safety environment.

## Non-goals

P10.22 does not lift Migration Freeze, execute migrations, connect to production databases, enable AI, weaken authorization/RLS, use real detainee data, or claim production readiness.
