# P10.31 — Audit & Correlation Release Contract

Status: PREPARED — synthetic contract.

Every material request receives request and correlation identifiers propagated through authorization, domain command, transaction, audit and outbox. Critical audit is immutable/append-only; corrections are correction events. Writer and verifier use identical canonical hash material, field order, serialization, encoding and hash version.

Audit records attribute actor, action, resource, result, request/correlation IDs, policy version and scope without passwords, bearer tokens or unnecessary sensitive payloads. Audit access is itself authorized by permission, scope and classification. Mandatory audit failure cannot be silently treated as successful critical mutation.

No production persistence or migration activation occurs here.
