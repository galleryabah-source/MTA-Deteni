# P10.31 — Audit & Correlation Release Contract

Status: PREPARED — synthetic contract.

Every material request receives a request ID and correlation ID. The same correlation context propagates through authorization, domain command, transaction, audit and outbox.

Critical audit records are immutable. Corrections are append-only correction events. Hash-chain writer and verifier use the same canonical material, field order, serialization and hash version.

Audit records must attribute actor, action, resource where applicable, result, request/correlation identifiers, policy version and scope without storing passwords, session secrets, bearer tokens or unnecessary sensitive payloads.

Audit access itself is protected by authorization, scope and classification. A failed mandatory audit write cannot be silently treated as a successful critical mutation.

This checkpoint does not activate production persistence or change the migration freeze.
