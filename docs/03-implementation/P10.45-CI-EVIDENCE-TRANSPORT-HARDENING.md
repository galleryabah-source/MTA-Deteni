## Transport rule

CI evidence must distinguish:

- **PASS** — test assertions executed and evidence is independently observable;
- **FAIL** — assertions executed and a reproducible application/test failure is observable;
- **BLOCKED** — execution or evidence transport was unavailable, malformed, or unverifiable.

A GitHub Actions `conclusion=failure` with unavailable step/log evidence is not sufficient to claim a code failure.
