## Integrity Rules

1. Transaction metadata binds transaction, actor, correlation and aggregate identity.
2. Transaction failure must roll back; successful work commits exactly through the transaction boundary.
3. Outbox consumption requires a consumer identity and explicit acknowledge/release semantics.
4. Read models are derived state and may be rebuilt from committed operational evidence.
5. Projection failure must never be interpreted as authorization for direct domain mutation.
6. Repository remains synthetic-only; AI remains OFF; migration freeze remains TRUE.
7. PostgreSQL implementation is a contract, not an authorization to connect to production or mutate schema.
