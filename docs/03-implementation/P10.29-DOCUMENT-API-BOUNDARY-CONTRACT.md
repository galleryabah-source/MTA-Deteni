# P10.29 — Document API Boundary Contract

Status: PREPARED — synthetic contract only.

## Scope

The application must expose document operations through a server-side application boundary. Required outputs remain `TEMPORARY_EXIT_PERMISSION` (Surat Izin Keluar Sementara) and `ESCORT_ASSIGNMENT_LETTER` (Surat Tugas Pengawalan).

## Flow

```text
request
→ authentication
→ authorization (document permission + scope + duty/policy)
→ document state check
→ immutable template manifest/version/hash binding
→ deterministic DOCX generation
→ artifact hash/identity
→ lifecycle transition
→ mandatory audit
→ outbox where downstream work exists
```

Generation must not allow arbitrary client-selected templates or template paths. Production template identity/version/hash is server-controlled.

## Issue boundary

Issuance requires the lifecycle and authorization conditions already established by P10.18–P10.21. The generated artifact remains bound to its template version and SHA-256.

## Download boundary

Download does not expose an unrestricted storage path. It requires a persistent artifact grant bound to document/artifact/hash/object/actor/scope/expiry and uses atomic single-use consumption.

## Security

No document content, detainee PII, credentials, tokens or secrets enter synthetic evidence. Provider/network calls are never performed inside the critical transaction.
