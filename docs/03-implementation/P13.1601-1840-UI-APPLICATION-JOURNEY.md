# MTA DETENI — P13.1601–P13.1840

## Objective

Connect the governed application core to an eventual operator-facing experience without weakening authorization, evidence, or release governance.

## Checkpoints

- P13.1601–1640 — Application Shell Contract
- P13.1641–1680 — Navigation State Contract
- P13.1681–1720 — Report Preview / Download Boundary
- P13.1721–1760 — Synthetic Operator Journey
- P13.1761–1800 — Cross-Module Journey Acceptance
- P13.1801–1840 — UI-to-Release Evidence Binding

## Safety

The shell is synthetic-only. Operational mutation requires an online, trusted state but still remains subject to the authoritative authorization and transaction boundaries already established by the application core.

Report preview is non-mutating. Download is permitted only for an artifact with an approval binding. UI journey acceptance cannot authorize production access or enable AI.

The synthetic journey models LOGIN → DASHBOARD → DETAINEE_CONTEXT → OPERATIONAL_ACTION → REPORT_PREVIEW → HUMAN_REVIEW → APPROVAL → OUTPUT → AUDIT.

Cross-module acceptance is synthetic and does not replace domain ownership, authorization, or authoritative operational evidence.

## Certification

The regression test is committed but execution is not certified until observable CI/local command telemetry is available.
