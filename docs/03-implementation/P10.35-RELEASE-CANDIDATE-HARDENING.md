# P10.35 — Release Candidate Hardening

**Status:** PREPARED / FAIL-CLOSED
**Data:** SYNTHETIC ONLY
**AI:** OFF
**Migration Freeze:** TRUE

## Objective

Consolidate the P10 runtime, document-output, authorization, transaction, audit, outbox, artifact-handoff and security contracts into one release-candidate gate. This checkpoint does not activate production behavior.

## RC invariants

1. Main remains untouched by implementation commits.
2. Migration Freeze remains TRUE.
3. AI remains OFF.
4. Test data is synthetic only.
5. Authentication is required before protected operations.
6. Authorization is deny-by-default and server-enforced.
7. Scope, duty, classification and separation-of-duties constraints are mandatory.
8. Super Admin does not imply operational authority.
9. Document output is restricted to approved immutable template bindings.
10. DOCX artifact identity and SHA-256 must remain bound through lifecycle and handoff.
11. Artifact download requires a persistent single-use grant bound to actor, scope, object and expiry.
12. Critical mutations commit domain state, audit and outbox atomically.
13. External providers are post-commit only.
14. Idempotency prevents duplicate critical effects and detects conflicting replay.
15. Evidence must distinguish PASS, FAIL, BLOCKED and SKIPPED_BY_SAFETY_GATE.
16. No certification claim is valid without independently observable CI evidence.

## Release-candidate gate

The gate is complete only when the synthetic regression suite, evidence-integrity verification, required-file preflight and workflow artifact publication are independently observable. A missing step log, missing evidence artifact, unsafe environment, or unverified dependency is a blocker, not a PASS.

## Explicit exclusions

No migration, production database operation, production credential, real detainee data, real document, production provider call, scanner/device activation, AI activation, or schema modification is permitted under this checkpoint.

## Exit criteria

- [ ] deterministic P10 regression gate passes;
- [ ] evidence integrity passes;
- [ ] evidence artifact is available from GitHub Actions;
- [ ] step-level CI evidence is independently observable;
- [ ] safety gate remains enforced;
- [ ] all certification blockers are explicitly tracked.
