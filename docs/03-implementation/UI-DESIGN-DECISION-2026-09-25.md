# MTA DETENI — UI Design Decision Record

**Date:** 25 September 2026  
**Decision:** APPROVED / LOCKED

The user approved the supplied desktop/web MTA DETENI design as the fixed visual baseline.

The design is the light modern desktop interface with:
- fixed left sidebar;
- white/light workspace;
- blue active navigation;
- institutional hero banner;
- four KPI cards;
- six quick-action cards;
- status and trend analytics;
- recent activity;
- recent detainee list;
- modern enterprise/government visual language.

The design must be treated as a **design freeze**. Future implementation work is limited to fidelity, correctness, accessibility, performance, icon consistency, spacing, and functional integration. Do not introduce another visual direction without an explicit new approval.

The sidebar must use exactly one icon per menu item and must not show duplicated icons or a visible vertical scrollbar in the normal desktop dashboard viewport.
