# P11.161–P11.224 — Lifecycle Consistency Gate

## Scope

The synthetic workflow models the complete temporary-exit lifecycle from request through completion and connects lifecycle state to operational headcount and QR context without bypassing the domain state machine.

## Invariants

1. State order remains `REQUESTED → VALIDATED → APPROVED → DOCUMENTED → ESCORT_ASSIGNED → DEPARTED → RETURN_PENDING → RETURNED → COMPLETED`.
2. Departure decrements synthetic headcount by one.
3. Return increments synthetic headcount by one.
4. Departure requires accepted `TEMPORARY_EXIT` QR context.
5. Temporary-exit `COMPLETED` carries no deportation QR context.
6. Deportation is a separate operational workflow/context and must never be inferred from temporary-exit completion.
7. Any target drift away from `SYNTHETIC` blocks the contract.

## Architecture

This is a contract-level cross-domain consistency layer. It does not replace the temporary-exit domain service, authorization boundary, persistence boundary, audit/outbox semantics, or future real operational rules.

## Safety

Migration Freeze remains TRUE. AI remains OFF. No production access, live database, schema migration, or real detainee data is introduced.
