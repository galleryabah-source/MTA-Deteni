# P10.181–P10.188 — Governed Non-Production Execution Preflight

## Status

- Checkpoint: **P10.188**
- Classification: **BLOCKED_PENDING_GOVERNANCE**
- Migration Freeze: **TRUE**
- AI: **OFF**
- Data: **Synthetic only**
- Live PostgreSQL execution: **BLOCKED**

## Purpose

This checkpoint converts the P10.173–P10.180 evidence boundary into a deterministic preflight contract for a future controlled non-production PostgreSQL verification. It does not execute SQL, connect to a live database, lift Migration Freeze, enable providers, or authorize production access.

## P10.181 — Immutable preflight identity

A run must bind:

- repository and branch/ref;
- exact commit SHA;
- preflight version;
- operator identity reference;
- governance approval reference;
- target reference;
- evidence destination reference;
- rollback-owner reference.

Missing identity is a hard BLOCK.

## P10.182 — Environment safety gate

Required values:

```text
MIGRATION_FREEZE = TRUE
AI_ENABLED = FALSE
DATA_CLASS = SYNTHETIC_ONLY
TARGET_CLASS = NON_PRODUCTION
```

Any mismatch is a hard BLOCK.

## P10.183 — Target allow-list gate

The target must be explicitly identified as an approved non-production target using a synthetic test-contract reference. Production-looking, unapproved, or ambiguous targets fail closed.

The application must not infer authorization from hostname, database name, or operator intent.

## P10.184 — Artifact integrity gate

Before execution, verify SHA-256 identities for:

- migration artifact;
- schema contract;
- RLS policy artifact;
- regression suite;
- audit/integrity verifier;
- rollback plan;
- release manifest;
- evidence packet.

Hash mismatch = BLOCK.

## P10.185 — Prerequisite gate

The following must be PASS before execution eligibility can be established:

1. synthetic-data enforcement;
2. authentication regression;
3. authorization regression;
4. RLS policy contract checks;
5. transaction/idempotency checks;
6. audit-integrity checks;
7. provider-isolation checks;
8. migration safety checks;
9. rollback checks;
10. evidence-integrity checks.

A missing result is not equivalent to PASS.

## P10.186 — Execution-mode gate

Only the explicit mode below is eligible for controlled execution:

```text
MODE = GOVERNED_NONPROD_VERIFICATION
```

The following are permanently ineligible through this path:

```text
PRODUCTION_MIGRATION
PRODUCTION_DATA_IMPORT
PROVIDER_ACTIVATION
AUTONOMOUS_RELEASE
```

## P10.187 — Fail-closed decision

Preflight produces exactly one decision:

```text
ELIGIBLE_FOR_GOVERNED_NONPROD_VERIFICATION
```

or:

```text
BLOCKED
```

No third state may silently authorize execution.

Eligibility is not execution authorization; governance approval remains an independent control.

## P10.188 — Evidence handoff

A valid preflight produces a signed/hashed handoff containing:

- preflight result;
- all prerequisite results;
- exact commit SHA;
- environment flags;
- artifact hashes;
- target reference;
- governance reference;
- timestamp;
- evidence-manifest hash.

The handoff is immutable after construction. Any mutation invalidates the packet.

## Safety invariant

> **No preflight result can itself lift Migration Freeze or authorize production execution.**

## Release sequence

`P10.173–180 Evidence Packet → P10.181–188 Preflight → explicit governance clearance → P10.189–196 controlled non-production verification`
