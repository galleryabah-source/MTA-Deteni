# MTA DETENI — P10.2 Placement Domain Boundary

**Status:** EXECUTABLE FOUNDATION / NOT CERTIFIED

## Scope

P10.2 extends the P10.1 application boundary to the D4 placement-transfer concern using synthetic data only.

Roadmap D4 explicitly includes placement transfer, movement ledger, headcount, barcode/QR, block/room operational lists and temporary exit. This checkpoint isolates placement first so its invariants can be tested before database integration.

## Flow

`Request Context → Authorization → Placement Validation → Transaction → Audit → Outbox`

## Contract

A placement transfer requires:

- detainee identifier;
- current/target placement context;
- target block and room;
- active detainee state;
- target capacity availability;
- actor, scope, request ID and correlation ID;
- idempotency key.

The command rejects missing context, invalid state, non-active detainees and exhausted capacity before domain mutation.

## Security

Placement permission is `deteni.placement.transfer`. Existing deny-by-default authorization remains mandatory. The caller's payload is not a source of authorization authority.

## Transactional guarantees

On successful execution the synthetic transaction boundary records:

1. placement domain mutation;
2. audit event;
3. outbox event;
4. idempotency fingerprint.

Replay does not duplicate critical side effects. Reuse of an idempotency key for a materially different target produces `CONFLICT`.

## Explicit limitations

The current store is an in-memory test double. These tests do not prove PostgreSQL locking/isolation, real capacity concurrency, real HTTP middleware, or production deployment behavior.

## Safety

No schema migration, production database, real detainee data, credentials, external provider, or AI execution is introduced. `MIGRATION_FREEZE=true` and `AI_ENABLED=false` remain required.

## Gate

P10.2 is an executable foundation, not a production certification. Real database integration remains blocked until database contract reconciliation and the relevant security/integration evidence gates are explicitly passed.
