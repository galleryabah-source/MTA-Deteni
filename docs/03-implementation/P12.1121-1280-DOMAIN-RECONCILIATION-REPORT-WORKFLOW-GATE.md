# P12.1121–1280 — Domain, Reconciliation, Report and Operator Workflow Gate

## P12.1121–1160 — Domain Aggregate Composition

RAP, PERKES, KAMTIB, SUBBAG TU and LEADERSHIP records participating in one operation must preserve the same aggregate, detainee and correlation identity. Identity drift is a hard failure.

## P12.1161–1200 — Reconciliation Evidence

Reconciliation produces explicit MATCH/MISMATCH evidence. A mismatch blocks promotion into a trusted downstream operational/reporting state; it is never silently normalized.

## P12.1201–1240 — Report Artifact

Report artifacts retain the reporting snapshot provenance and a deterministic content hash. The artifact contract does not itself authorize distribution or approval.

## P12.1241–1280 — Controlled Operator Workflow

The operator workflow is deliberately sequential:

`DRAFT → VALIDATED → PREVIEW → REVIEW → APPROVED → GENERATED`

Undeclared transitions are denied. Generation is therefore downstream of review and approval.

## Integrated invariant

`Domain Aggregate → Reconciliation → Evidence-backed Snapshot → Report Artifact → Review/Approval → Generated Output`
