# P10.13 — Approved Database Integration Execution Gate

## Status

GATE PREPARED — execution remains blocked while `MIGRATION_FREEZE=TRUE`.

## Purpose

P10.13 converts the P10.12 database package into a fail-closed execution gate. It does not execute migration, RLS deployment, repository integration, or production database operations.

## Preconditions

All conditions below are mandatory before execution:

- [ ] explicit governance approval to lift Migration Freeze;
- [ ] approved target environment and database identity;
- [ ] approved actor-to-identity mapping;
- [ ] approved authoritative scope mapping;
- [ ] approved PostgreSQL role and privilege model;
- [ ] approved RLS policies with no permissive placeholder;
- [ ] approved migration artifact checksum/version;
- [ ] backup/restore evidence and rollback window;
- [ ] synthetic test dataset only until data-governance approval permits otherwise;
- [ ] audit/outbox evidence destination is available;
- [ ] provider/network calls remain outside the critical database transaction;
- [ ] CI produces observable step-level evidence.

## Execution sequence after approval

`Freeze Approval → Environment Verification → Migration Checksum Verification → Controlled Migration → Schema Verification → RLS Deployment → Role Tests → Repository Integration → Concurrency Tests → Rollback Drill → Evidence Review`

## Hard stops

Execution MUST stop immediately if:

- Migration Freeze is still TRUE;
- database identity does not match the approved target;
- migration checksum differs from the approved artifact;
- actor or scope mapping is absent or ambiguous;
- RLS or privileges are broader than the approved contract;
- any unauthorized browser write path exists;
- concurrency evidence cannot prove exactly one successful consume;
- audit/outbox atomicity cannot be demonstrated;
- CI evidence is missing or non-observable;
- real detainee data, credentials or provider secrets would enter the test boundary.

## Evidence required

The execution record must capture, without sensitive payloads:

- environment/database identity;
- migration artifact version and checksum;
- schema objects and constraints;
- RLS enabled state and policy definitions;
- role privilege matrix;
- identity/scope mapping test results;
- concurrent consume row counts and final state;
- expiry, actor, scope, object and revoke race results;
- rollback evidence;
- audit event identifiers and outbox identifiers;
- provider invocation timestamp proving post-commit isolation;
- CI run, job and step evidence.

## Certification rule

P10.13 is NOT CERTIFIED merely because a migration executes. Certification requires independently observable evidence for schema, identity/scope isolation, RLS, concurrency, rollback, transaction atomicity, audit/outbox integrity and runtime integration.

## Safety boundary

Until every precondition is explicitly approved, the only permitted action is preparation and static verification. No DDL or production connection is authorized by this document.
