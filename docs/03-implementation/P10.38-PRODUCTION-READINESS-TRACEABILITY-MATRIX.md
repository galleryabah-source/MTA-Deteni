## Gate semantics

`READY FOR GOVERNANCE REVIEW` means the architecture and evidence package are coherent enough for an authorized governance decision. It does **not** mean production-ready.

`READY FOR PRODUCTION` requires every production blocker to be resolved and independently evidenced. No single administrative role can self-approve this transition.

## Hard stop

Migration Freeze remains TRUE until an explicit governance decision is recorded outside the application implementation path.
