# P10.32 — Critical Transaction Release Matrix

Status: PREPARED — synthetic contract.

| Operation | AuthZ first | Domain transaction | Audit mandatory | Outbox after commit | Idempotency |
|---|---|---|---|---|---|
| Leave critical transition | yes | yes | yes | if downstream | yes |
| Document issue | yes | yes | yes | if downstream | yes |
| Artifact grant creation | yes | yes | yes | yes | yes |
| Artifact consume | yes | atomic DB transition | yes | no provider in transaction | yes/atomic |
| RBAC mutation | yes | yes | yes | cache invalidation | optimistic version |

Failure policy:

- domain failure → rollback;
- audit failure inside critical transaction → rollback;
- outbox failure inside critical transaction → rollback;
- commit failure → no committed operation may be reported as success;
- provider failure after commit → outbox retry/dead-letter, never retroactively mutate the committed transaction.

This matrix preserves the existing transaction architecture and does not authorize schema migration or production execution.
