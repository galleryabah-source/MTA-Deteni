## Failure-injection rule

Any unexpected ALLOW, duplicate terminal transition, provider call before commit, missing audit/outbox record, scope bypass, or evidence-integrity mismatch is a release-candidate failure.

A blocked safety gate is not converted to PASS. Production activation requires separate governance approval and independently observable evidence.
