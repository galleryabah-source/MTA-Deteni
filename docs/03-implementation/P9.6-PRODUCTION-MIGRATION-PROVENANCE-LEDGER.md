## Important distinction

This ledger does **not** claim that every missing repository migration is currently required to be re-applied to production.

It records a provenance problem:

```text
PRODUCTION
  migration history
       +
LIVE DATABASE STATE
       ↓
must be traceable to
       ↓
REPOSITORY SOURCE
       ↓
replayable / auditable
```

The correct remediation is to recover or otherwise establish the authoritative source for each missing migration, compare it against the live object contract, and record the provenance without mutating production.
