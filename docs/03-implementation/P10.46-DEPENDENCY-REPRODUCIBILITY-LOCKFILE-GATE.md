# P10.46 — Dependency Reproducibility & Lockfile Gate

Status: PREPARED / CERTIFICATION BLOCKED UNTIL REPRODUCIBLE DEPENDENCY STATE EXISTS.

## Objective

Make dependency reproducibility an explicit release gate without weakening the Migration Freeze or inventing dependency state.

## Contract

1. `package.json` is the declared dependency source.
2. A reviewed `package-lock.json` is required for production certification.
3. CI may use `npm install --ignore-scripts --no-audit --no-fund` only as a temporary bootstrap while no lockfile exists.
4. Once a reviewed lockfile exists, CI must use `npm ci --ignore-scripts --no-audit --no-fund` as the reproducible install path.
5. No lockfile is generated by this checkpoint from guessed or unverified dependency resolution.
6. Missing lockfile is a BLOCKED certification condition, not a PASS.
7. Dependency installation never enables AI, provider calls, production DB access, or migration execution.

## Required evidence before certification

- `package.json` SHA-256 recorded.
- reviewed `package-lock.json` committed to the controlled branch.
- lockfile corresponds to the declared package manifest.
- CI demonstrates `npm ci` against the reviewed lockfile.
- CI transport evidence identifies commit SHA, Node/npm versions, lockfile presence, and command outcome without exposing secrets.

## Decision

P10.46 does not lift Migration Freeze and does not certify production readiness.
