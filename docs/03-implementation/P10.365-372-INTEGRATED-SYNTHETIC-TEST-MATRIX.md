## Primary E2E path

## Mandatory test classes

1. Authorization: allow/deny by actor, role, permission, domain, and scope.
2. State: valid and invalid transitions across the full chain.
3. Concurrency: movement, revoke, expiry, departure, numbering, and approval races.
4. Idempotency: repeated commands produce one material result.
5. Integrity: audit/outbox failure causes transaction rollback.
6. Data isolation: PERKES fields are inaccessible through ordinary RAP/KAMTIB paths.
7. Document integrity: exact template version, required placeholders, stable hash, controlled numbering.
8. QR safety: scan never bypasses server authorization/current-state checks.
9. History: corrections are reconstructable through events, not destructive overwrites.
10. Recovery: deterministic behavior after timeout, duplicate delivery, and failed downstream artifact generation.

## Acceptance rule

The test matrix is synthetic and deterministic. A PASS result is evidence for the governed verification chain, not production authorization. Any security or integrity ambiguity is classified BLOCKED/FAIL and prevents progression to pilot.
