# P10.325–P10.332 — Movement & Headcount Implementation Scaffold

## Status

- Classification: **SCAFFOLD_READY**
- Migration Freeze: **TRUE**
- AI: **OFF**
- Data: **Synthetic only**

## Components

```text
Movement command
 → authorization/scope
 → current-state predicate
 → movement event transaction
 → placement projection
 → headcount projection
 → audit/outbox
```

Required operations: recordMovement, getCurrentMovementState, getMovementTimeline, getHeadcount, reconcileHeadcount.

Headcount is derived, with explicit reconciliation exceptions. Movement events are append-only. Concurrent requests must use atomic state predicates and idempotency. QR/barcode input is normalized as an identification signal and never treated as authority.

## Test gate

Synthetic tests: normal movement; concurrent movement; stale state; wrong scope; invalid destination; duplicate replay; headcount reconciliation; compensating event; scan without authority; audit failure rollback.

## Safety

No migration or live database mutation is authorized by this scaffold.
