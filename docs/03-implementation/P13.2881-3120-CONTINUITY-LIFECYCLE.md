# MTA DETENI — P13.2881–3120 Continuity Lifecycle

## Scope

This checkpoint strengthens the local-first continuity model without creating production authority or changing the database schema.

### P13.2881–2920 — Continuity session lifecycle
- Explicit ACTIVE, PAUSED, RECONNECTING, CLOSED, REVOKED and BLOCKED states.
- Only ACTIVE sessions may mutate through the canonical authorization boundary.
- Terminal CLOSED/REVOKED/BLOCKED states cannot transition back to an active state.

### P13.2921–2960 — Device revocation
- Revocation is fail-closed.
- A revoked pairing cannot create a new authorized session.
- Active sessions associated with a revoked device are represented as REVOKED.
- Revocation does not itself grant or alter operational authority.

### P13.2961–3000 — Sync conflict resolution
- Divergent operations are explicit conflicts.
- Conflicts require review; no silent last-write-wins policy is introduced.
- Resolution requires an explicit human resolution note.
- BLOCKED remains available for conflicts that cannot safely be resolved.

### P13.3001–3040 — Evidence chain sealing
- Evidence is ordered and linked to the preceding evidence fingerprint.
- A chain can be sealed only after integrity verification.
- Sealed chains reject further append operations.
- The current fingerprint is a deterministic integrity aid, not a cryptographic signature.

### P13.3041–3080 — Synthetic E2E continuity acceptance
The acceptance contract covers pairing → active session → offline read-only → queue → replay → integrity → conflict review → device revocation → recovery → human sign-off.

### P13.3081–3120 — Continuity release gate
READY requires all continuity controls plus `migrationFreeze=true`, `aiEnabled=false`, and `productionAuthorized=false`.

## Governance

No production access, live PostgreSQL execution, schema migration, real detainee data, credential material or external operational feed is introduced by this checkpoint.

All acceptance data is synthetic. Execution certification requires observable CI or local command telemetry and is not inferred from source creation alone.
