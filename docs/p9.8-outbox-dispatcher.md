# P9.8 — Outbox Dispatcher Boundary

Status: IMPLEMENTED / DATABASE-VERIFIED / APPLICATION PUBLISHER PENDING

The dispatcher boundary is service-role-only and operates on the private `mta_internal.outbox_events` table.

## State machine

PENDING → PROCESSING → PUBLISHED

Failure:

PROCESSING → PENDING

with bounded backoff and `last_error`.

## Claim semantics

`claim_outbox_events(limit, lease_seconds)` uses row locking with `FOR UPDATE SKIP LOCKED`, increments `attempts`, and records `locked_at`.

The claim function is not exposed to `anon` or `authenticated`.

## Release semantics

`release_outbox_event(event_id, error, backoff_seconds)` returns a failed processing event to PENDING and records bounded diagnostic information.

## Completion semantics

`complete_outbox_event(event_id)` transitions only PROCESSING events to PUBLISHED and records `published_at`.
