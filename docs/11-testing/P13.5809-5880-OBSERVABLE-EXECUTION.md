# P13.5809–5880 — Observable Execution & Evidence Acceptance

## Objective

Turn the execution harness from a declared capability into an auditable, reproducible controlled-non-production observation gate without crossing production, migration, AI, or real-data boundaries.

## Gate sequence

1. **ARCH-5809–5822** — static architecture/governance contract gate.
2. **BUILD** — Node/npm and production TypeScript typecheck.
3. **REG** — JavaScript regression and TypeScript domain tests.
4. **EVIDENCE** — execution evidence captures commit SHA, run identity, environment, timestamps, control IDs, exit codes and output.
5. **ARTIFACT** — evidence directory is uploaded for review.
6. **IDENTITY** — evidence execution identity must match the triggering CI run and commit.
7. **SURFACE** — controlled application-surface checks may proceed only after observable CI telemetry exists.

## Acceptance rules

- A green-looking workflow with zero job steps is **NOT evidence of PASS**.
- Missing job telemetry is an **observation/infrastructure blocker**.
- `NOT_RUN`, missing artifacts, identity mismatch, unexpected control IDs, or environment drift remain non-certified.
- Static contract PASS does not imply runtime PASS.
- Runtime PASS does not imply production readiness.
- No schema migration is authorized by this gate.
- No live PostgreSQL/Supabase credential is required by this gate.
- Repository fixtures remain synthetic-only.

## Controlled application-surface target

The next runtime surface must prove the chain at the domain boundary using synthetic fixtures:

`command → authorization → operational envelope → domain transition → idempotency → immutable timeline/audit → evidence → reconciliation → read model`

For movement/temporary-exit/QR/reporting, the target is contract verification first; real deployment and real detainee data remain outside scope.

## Current blocker

GitHub Actions has previously produced completed failures with no reported steps and no downloadable logs. Until a run exposes real step telemetry, the project must remain **OBSERVATION PENDING** even if static contract checks are correct.
