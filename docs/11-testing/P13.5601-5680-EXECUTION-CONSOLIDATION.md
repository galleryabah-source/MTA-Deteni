# MTA DETENI — P13.5601–5680 Execution Consolidation

## Purpose

Convert the existing contract-heavy roadmap into a single controlled non-production execution gate. This checkpoint does not authorize production access, real detainee data, live operational WhatsApp/OCR intake, or database migration.

## Execution order

```text
1. Repository integrity
2. Typecheck
3. JavaScript regression
4. TypeScript/domain tests
5. Local runtime health
6. Browser role journeys
7. LAN multi-device continuity
8. Offline/read-only and reconnect behavior
9. Report rendering and visual evidence
10. Backup/restore/replay rehearsal
11. Security regression
12. Evidence aggregation
13. Human review gate
```

## Evidence rule

A control is `PASS` only when an observable execution artifact exists and is bound to:

- control ID;
- execution identity;
- environment;
- commit SHA;
- timestamp;
- exit/result status;
- artifact identity where applicable.

`NOT_RUN`, missing evidence, unexpected control IDs, target mismatch, identity drift, or non-zero execution remain non-certified.

## Required evidence matrix

| Area | Required control family | Status until observed |
|---|---|---|
| Build | BUILD-* | NOT_RUN |
| Regression | REG-* | NOT_RUN |
| Runtime | RUNTIME-* | NOT_RUN |
| Browser/RBAC | UI-* / AUTH-* / RBAC-* | NOT_RUN |
| LAN | LAN-* | NOT_RUN |
| Offline/reconnect | OFFLINE-* | NOT_RUN |
| Report | REPORT-* | NOT_RUN |
| Recovery | DR-* / RECOVERY-* | NOT_RUN |
| Security | SEC-* | NOT_RUN |

## Stop conditions

Execution stops and returns to engineering if any of the following occurs:

- real operational data is detected;
- production credentials or endpoints are detected;
- migration is attempted while Migration Freeze is TRUE;
- AI is activated without an approved controlled test boundary;
- an authorization boundary is bypassed;
- an audit event is missing for a mandatory critical mutation;
- report output diverges from the approved template without an accepted exception;
- offline/reconnect creates silent data loss or unauthorized state transition.

## Release semantics

The only permitted progression is:

```text
CONTRACT_READY
  → OBSERVATION_PENDING
  → OBSERVATION_INCOMPLETE | CONTROLLED_NONPROD_CERTIFIED
```

Production authorization is a separate governance decision and cannot be inferred from this gate.
