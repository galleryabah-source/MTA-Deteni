## Evidence rules

- `NOT_RUN` is never converted to `PASS`.
- Every PASS requires an observable output identity.
- Evidence integrity uses SHA-256 over a canonical payload.
- Unexpected control identities are rejected.
- Synthetic-only execution is mandatory.
- Production authorization must remain false.
- Schema migration remains frozen.

## Execution order

Foundation checks → application harness → role journeys → continuity → report rendering → recovery → security → aggregate evidence.

A failure is a defect signal. Fixes must be narrowly scoped, preserve the integrated architecture and be followed by retesting of the affected control and dependent controls.

## Gate

P13.5520 is complete only when the matrix has actual observable results and the resulting evidence package is internally consistent. It does not authorize production deployment.
